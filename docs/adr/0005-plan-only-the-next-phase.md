# Agents plan only the next phase

Agents tend to plan far ahead: they settle details of phases months away, then defend those plans when the work reaches them, even though the code will have changed by then. On 2026-10-28 an agent did this, and the user corrected it.

Nothing is planned or decided about a later phase unless it affects the current phase or the next one. A phase is planned when it becomes the next one.

The user wrote on 2026-10-28: "no phase should be planned beyond the next one. no decision should be made about any future phases unless it affects the current or next stage."

Reversing this would cost little money but would bring back planning that goes stale. No figure is recorded.
