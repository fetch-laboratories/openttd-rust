# Root takes stock after every 12 merges

A stocktake is root's periodic measurement of progress. Each one costs agent-hours and machine time and takes an implementer's slot while it runs. On 2026-11-06 stocktakes ran after every second merge, so a four-line change and a two-line change each triggered a full stocktake and profile.

After every 12 merges, root takes stock: it measures progress and profiles the game's speed.

On 2026-11-06 an agent offered numbers from 2 to 50, and the user wrote: "there's a whole lot of fucking numbers between 2 and 50. Fucking pick one… do 6-12." The agent chose six. On 2026-11-08 the user wrote: "skip this and move it to a 12 integration cadence." [docs/speed.md](../speed.md) holds the profiling steps.
