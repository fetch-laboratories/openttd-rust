# Worksets

The worksets of the complete-file passes ([#734](https://github.com/fetch-laboratories/openttd-rust/issues/734)): each line names a workset and its Rust files, relative to `rust/openttd-kernels/src`. `python3 tools/code-standards-inventory.py --worksets` reads this file with `migration/finished-files.txt` and prints each workset's finished files and lines left, the Rust files in no workset and the entries without a file.
